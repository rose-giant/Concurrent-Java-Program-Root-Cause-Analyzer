**Where to apply it** *(file:line range)*:

`Main.main`. The old source is on a single line, so line ranges are not meaningful. `IntHolder` is unchanged.

**Description of the fix:**

Replace the fixed thread pool and its two lambda tasks with two `Thread`s built from anonymous `Runnable`s, start them, and `join()` both. Remove `shutdown()` and `awaitTermination(...)`.

**Code sketch**

```java
// before

ExecutorService es = Executors.newFixedThreadPool(2);
es.execute(() -> { holder.set(1); });
es.execute(() -> { holder.get(); });
es.shutdown();
es.awaitTermination(1, TimeUnit.SECONDS);
```

```java
// after

Thread t1 = new Thread(new Runnable() {
    @Override
    public void run() {
        holder.set(1);
    }
});

Thread t2 = new Thread(new Runnable() {
    @Override
    public void run() {
        holder.get();
    }
});

t1.start();
t2.start();

t1.join();
t2.join();
```

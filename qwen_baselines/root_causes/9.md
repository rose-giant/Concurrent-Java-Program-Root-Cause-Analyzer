## 4. Suggested solution

**Fix type**

* [ ] Add or widen synchronization (synchronized / lock)

**Where to apply it** *(file:line range)*:

`Main.java:12-20`, where `t1` and `t2` are created using lambdas capturing `tracker`.

**Description of the fix:**

Replace the lambda expressions used for the thread bodies with explicit `Runnable` implementations and make the captured tracker reference explicitly `final`.

**Code sketch**

```java
// before

Thread t1 = new Thread(() -> {
    tracker.modifyCoordinates("R1", "Zone C");
    System.out.println("R1 coordinates: " + tracker.checkCoordinates("R1"));
});

Thread t2 = new Thread(() -> {
    Map<String, String> snapshot = tracker.getAllCoordinatesStatic();
    System.out.println("Snapshot: " + snapshot);
});
```

```java
// after

final DelegatingRobotTracker tracker = new DelegatingRobotTracker(initial);

Thread t1 = new Thread(new Runnable() {
    @Override
    public void run() {
        tracker.modifyCoordinates("R1", "Zone C");
        System.out.println("R1 coordinates: " + tracker.checkCoordinates("R1"));
    }
});

Thread t2 = new Thread(new Runnable() {
    @Override
    public void run() {
        Map<String, String> snapshot = tracker.getAllCoordinatesStatic();
        System.out.println("Snapshot: " + snapshot);
    }
});
```
